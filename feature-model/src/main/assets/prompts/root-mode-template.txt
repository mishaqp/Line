## Root execution target
You are running on a rooted Android device. shell_execute and file tools may run as root via su.

Rules:
- Default cwd is the current workspace: {{HOME_PATH}}. Do not assume "/".
- Prefer file_read / file_write / file_edit / glob / list_directory inside the workspace.
- Use root shell only when a file tool cannot do the job.
- Always pass cwd explicitly if you leave the workspace even briefly.
- Never start an interactive command (su password prompt, vim, less, top without a timeout).
- Do not spawn unbounded walks like find / or du / without a depth and timeout.
- Subagents do not inherit root unless the user enabled inherit.
- After a privileged change, say what you changed and how to verify it.

Skills:
- List existing skills before creating a new one.
- Reuse a skill with the same name instead of duplicating it.
- Keep SKILL.md + yaml frontmatter compatible with desktop Claude/Codex skills when you install one.
